Alien Shooter Console Video Game

Description

This was a project I worked on for my programming final. It was a game run in the console which included multiple mechanics like movement, shooting, teleportation, EMP blasts, enemy alien ships, and rounds that progressed in difficulty.

Technologies Used

This project was created inside of Visual Studio Code and ran inside of the terminal. The project was coded in the C# language using the .NET framework.
